# AI-Based Stock Price Predictor 📈

This project combines real-time stock market data and news sentiment analysis using LSTM/Transformer models and FinBERT NLP.

## Features

- Uses Alpha Vantage API for real-time stock + news data
- FinBERT for sentiment analysis
- LSTM & Transformer forecasting in PyTorch
- Metrics: RMSE, MAPE, directional accuracy
